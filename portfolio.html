HTML CSS JavaScript

I built this portfolio website over winter break as a way to explore web development and practice UI design. My goal was to create something both functional and visually clean using vanilla HTML, CSS, and JavaScript — no frameworks, just fundamentals.

The site features a responsive navbar with a mobile hamburger menu, a hero section, a project portfolio with modal popups, a resume embed, and a contact page. It's hosted on GitHub Pages.

Book Website / Database

React Node.js MySQL Team Project

In my CS Practicum class, I worked in a team of 3 to develop a web application for a psychology professor to support their research. The project involved designing and building a MySQL database to store and manage research data, with a React + Node.js frontend for a responsive, user-friendly interface.

It was a great experience collaborating as a team and delivering a functional tool for real academic use. The project concluded with a final presentation to the department.

Taskr — Android App

Android Studio Firebase Java Team Project

In my Mobile Apps class, I collaborated with two classmates to build Taskr — an Android app functionally similar to TaskRabbit. The app connects users who need help with everyday tasks to people willing to complete them.

We used Firebase as the backend for real-time data updates and reliable storage, and developed the app in Android Studio. The project was a great introduction to mobile development and real-time database design.

REU — Boise State University

Cybersecurity Machine Learning Research Python

Over the summer, I participated in the Cloud Computing and Privacy REU at Boise State University. My research focused on adversarial attacks against intelligent malware detectors — specifically, how these AI systems can be manipulated and how they might be improved to withstand such attacks.

The program concluded with a presentation at the Idaho Conference on Undergraduate Research (ICUR 2024), where I shared our findings with undergraduate researchers from across the country. The photo above is from that presentation!
